# Citations V1

Status: implemented on `feat/citations-v1`. Claim↔source linkage for replies grounded in external/retrieved factual sources. Extends Web Search V1. Memory is not a citation source.

## Goal

When Nibie answers using real retrieved sources, users see which source supports which claim: inline markers and a Sources list. Citations survive reload. The model cannot invent citation metadata.

## Architecture

```text
Web Search V1 pipeline → WebContextInput[]
  → prepare SourceReference[] (server-owned; handles web:1…)
  → stamp cite_as into web context
  → LLM streams with [SOURCE:web:n] handles only
  → citation-aware stream filter → visible [n] + SSE sources
  → persist message_sources with assistant message
  → UI: markers + Sources (title, domain, safe URL)
```

| Piece | Role |
| --- | --- |
| `lib/citations/types.ts` | `SourceReference`, client `CitationSourceView` |
| `lib/citations/prepare.ts` / `attach.ts` | Deterministic handles from web inputs |
| `lib/citations/parse.ts` | Stream + batch transform; unknown handles dropped |
| `lib/citations/sanitize.ts` | Titles, URLs, excerpts, domains |
| `lib/citations/persist.ts` | `message_sources` insert/load |
| `lib/context/web-context.ts` | `cite_as: [SOURCE:web:n]` provenance |
| `app/api/chat/route.ts` | Prepare → stream filter → persist → SSE `sources` |
| `components/message-markdown.tsx` / `message-sources.tsx` | Markers + Sources list |

## Source identity

- Canonical id: `web:1`, `web:2`, … (also reserved: `room_file`, `attachment`)
- Model sees only `[SOURCE:web:n]` — never trusted to invent URLs/titles
- Display ordinals are 1-based over prepared sources for that message
- Unknown handles are sanitized to plain text (no fake citation)

## Persistence

Table `message_sources` (migration `0016_message_sources`): ordinal, kind, handle, title, url, domain, optional excerpt/source_id/retrieved_at. Owner RLS. Cascade with assistant message.

## Observability

Safe counts only: `citation.sources.prepared`, `citation.references.parsed`, `citation.references.invalid` with `sourceCount`, `citationCount`, `invalidCitationCount`, `requestId`. Never full fetched content.

## Out of scope

Deep Research, browser agents, model-invented URLs as metadata, Memory as a citation source, room_file/attachment citing UI (architecture ready).
