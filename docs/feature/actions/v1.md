# Actions / Tools V1

Status: implemented on `feat/actions-tools-v1`. Server-owned Action Runtime with one read-only Action (`web.search`). Not agents, not multi-tool loops, not connectors.

## Goal

Give Nibie a bounded, auditable path to **do one allowlisted thing** and feed a structured result into chat synthesis — without autonomous agents or model-supplied handlers.

## Architecture

```text
User message
  → decideWebSearch (deterministic; unchanged rules)
  → if search: Action Runtime → web.search → action_runs audit
       → structured sources → Citations + context (untrusted web fences)
       → model synthesis
  → if no search: Fast path unchanged (no Action)
```

| Module | Role |
| --- | --- |
| `lib/actions/types.ts` | ActionDefinition, capabilities, ActionResult, run statuses |
| `lib/actions/registry.ts` | Allowlist only; reject unknown IDs |
| `lib/actions/permissions.ts` | V1 enables `read`; mutations require future confirmation |
| `lib/actions/runtime.ts` | Validate → permission → execute (max 1 / generation) → audit |
| `lib/actions/tools/web-search.ts` | Wraps `lib/web` pipeline (SSRF, bounds, degrade) |
| `lib/actions/auto-web-response.ts` | Early SSE `action_start` / `action_result` / `action_error` + Stop |
| `drizzle/0019_action_runs.sql` | Owner-scoped audit table + RLS |

## First Action: `web.search`

- Capability: `read`
- Input: `{ query }` (Zod)
- Output items: title / url / snippet / provenance
- Automatic Web Search routing is preserved — when routing says search, the Action path runs instead of calling the pipeline ad hoc
- Citations V1 and Deep Research are unchanged (Deep Research does not go through Actions V1)

## Lifecycle & UI

`requested → running → completed | failed | cancelled` (`waiting_for_confirmation` reserved for later mutations).

Minimal UX: “Searching the web…” / “Used Web Search”. No agent dashboard.

## Safety

- Model cannot supply code, handler names, credentials, or permissions
- Stop → AbortSignal through runtime; cancelled is truthful; no further Actions after cancel
- Action / web bodies remain untrusted; failure injects an authoritative “do not claim you searched” instruction
- `action_runs.input_summary` is sanitized (no secrets/tokens/cookies)

## Out of scope

Agents, multi-tool loops, computer-use, code exec, Gmail/Calendar/GitHub/Drive mutations, MCP marketplace, OAuth platform, workflow builder, scheduled Actions, WRITE tools (`pin.create`, etc.).
