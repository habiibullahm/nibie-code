# Chat Transcript V1

Status: implemented on `feat/chat-transcript` (Issue #74). Copy one conversation’s readable dialogue from the existing thread `···` menu.

## Goal

Let a signed-in owner copy a clean plain-text transcript for a single conversation—without a new page, toolbar, share link, download surface, or account-export change.

## Architecture

```text
Sidebar ··· menu
  → Copy transcript → GET /api/conversations/:id/transcript → clipboard (plain text)
         │
         ▼
createSupabaseServerClient + getAuthenticatedUser
  → conversations by id + user_id (active or archived)
  → messages paged (TRANSCRIPT_PAGE_SIZE) ordered by position, id
  → sanitize assistant text; omit streaming/error rows
  → format plain (Markdown stripped) with roles + timestamps
```

| Piece | Role |
| --- | --- |
| `lib/chat/transcript.ts` | Turn selection, plain formatting, size caps |
| `app/api/conversations/[id]/transcript/route.ts` | Auth, origin, owner filter, paging, response headers |
| `components/chat-sidebar.tsx` | Menu entry |
| `components/chat-workspace.tsx` | Fetch / preview build, clipboard, notices |

Local preview builds the same plain format from mock conversation messages (no API).

## Transcript contents

- Title header, chronological user/assistant turns, role labels, ISO timestamps.
- Interrupted assistant turns keep a “Stopped” note.
- Assistant text passes through `sanitizeModelOutput` (hidden reasoning removed); Copy strips Markdown syntax via `markdownToClipboard().plain`.
- Streaming placeholders and error rows are omitted.
- No system/developer prompts, provider secrets, context diagnostics, or attachment binaries.

## Limits

- Message page size: 200 (`TRANSCRIPT_PAGE_SIZE`).
- Max messages: 5,000; max characters: ~2 MiB — oversized requests return 413 with a clear error (no silent truncation).

## Security

- Cookie session only; rejects `user_id` / `userId` / `user` query params.
- Origin mismatch → 403; missing conversation or other owner → opaque 404.
- Explicit `.eq("user_id", …)` plus RLS; `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`.
- No public unlisted URLs; no migrations or new env vars.

## Out of scope

Markdown download, account JSON export changes, share links, toolbars, microphone/speech transcripts, attachment file bytes, migrations.
